# Scalable Storage CEu 2

A GregTech Modern addon that adds a multiblock that can store a lot of items at once.

## Features

- A multiblock called the Storage Silo that stores one item type at a time with a base capacity of 4,000,000 items.
- Storage upgrades that raise capacity to 32M, 64M and 256M items.
- Storage upgrades that wear out over time and need to be automated.
- A void upgrade which destroys incoming items only when both storage and the output buses are full.
- Fancy GregTech status screen with capacity, contents, upgrade state and void mode.
